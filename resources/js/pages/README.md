# Comportamento por tela (`resources/js/pages/`)

Carregados sob demanda por `app.js` conforme `body[data-page]`.

| Arquivo | Tela | Referência |
|---|---|---|
| `central.js` | Visão geral: mapa, lista, filtros, ficha resumida, polling com um único dono | [central](../../../docs/referencia/codigo/frontend/central.md) |
| `multas.js` | Multas: blocos por origem, campos condicionais, prévia da velocidade considerada | [páginas](../../../docs/referencia/codigo/frontend/paginas.md#pagesmultasjs-páginas-multas-e-multas-form) |
| `planejar.js` | Planejar reforço: mapa de calor, justificativa só quando não é o sugerido | [páginas](../../../docs/referencia/codigo/frontend/paginas.md#pagesplanejarjs-página-planejar) |
| `sobre.js` | Sobre: cartão de autoria animado | [páginas](../../../docs/referencia/codigo/frontend/paginas.md#pagessobrejs-página-sobre) |
